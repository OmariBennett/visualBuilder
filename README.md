# visualBuilder

A browser-based visual builder for prototyping with HTML elements: live-DOM canvas in an iframe, element palette, properties panel, layer breadcrumb, undo/redo, and localStorage persistence. Vanilla TypeScript + Vite, no framework.

Extracted from the `toolBox` repo.

## Scripts

- `npm run dev` — start Vite, then open `/documents/html/visualBuilder/HTMLElementVisualBuilder.html`
- `npm test` — run the Vitest (jsdom) suite
- `npm run build` — type-check and build
